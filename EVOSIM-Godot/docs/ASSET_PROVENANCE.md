# Asset provenance

All models in assets/*.glb are original procedural Blender geometry generated by art/build_assets.py with deterministic seed 2407. Source scene: art/Grove-library.blend; mesh counts: art/asset-manifest.json. No downloaded marketplace assets, Terra Nil meshes/textures, subscription service or AI image raster assets are used.

Godot and Blender are external open-source tools. Their licenses remain applicable to the tools; no tool executable is bundled into this source folder. The generated models contain no third-party texture dependencies. UI now bundles unmodified DejaVu Sans Bold under the Bitstream Vera font license (DejaVu changes public domain); full notices are in assets/fonts/LICENSE-DejaVu.txt. The reference typeface was not identified or extracted. Terra Nil screenshots are comparison references supplied by the user or obtained from official Steam public previews; research/.gdignore excludes them from scene import and they must be excluded from a distribution. No new license grant for the user's own project has been chosen on their behalf.

Original SVG glyphs are authored in this repository; none are traced or extracted Terra Nil icons. The research folder is evidence only.

Articulated creatures: `art/build_creatures.py`, source `art/Creature-library.blend`, generated deer_/wolf_ body/head/leg/tail.glb, counts in `art/creature-manifest.json`. Original deterministic geometry and materials use the existing project helpers. Cosmetic joint animation is authored in GDScript; no downloaded rig/animation clips. `validation/pose_gallery.gd` displays deliberately synthetic pose inputs and labels them as tests; it is not a recording of autonomous behavior.
